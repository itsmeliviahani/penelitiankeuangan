Persetujuan & penyaring responden

Kuesioner ini ditujukan untuk mahasiswa aktif PKN STAN. Seluruh data yang terkumpul dalam penelitian ini akan digunakan untuk keperluan akademis dan dijamin kerahasiannya.

Pertanyaan penyaring

Petunjuk pengisian

Pilih satu jawaban yang paling sesuai dengan kondisi Anda. Skala yang digunakan adalah Likert 5 poin:

1 Sangat tidak setuju 2 Tidak setuju 3 Netral 4 Setuju 5 Sangat setuju

Sosialisasi Keuangan FS

FS1 Orang tua saya membicarakan masalah keuangan keluarga dengan saya sejak saya kecil.
Sangat tidak setuju Sangat setuju
FS2 Orang tua saya berbicara kepada saya tentang pentingnya menabung.
Sangat tidak setuju Sangat setuju
FS3 Orang tua saya mengajari saya cara berbelanja secara cerdas.
Sangat tidak setuju Sangat setuju
FS4 Saya memperoleh informasi mengenai hal-hal keuangan dari lingkungan pertemanan di kampus.
Sangat tidak setuju Sangat setuju

Sikap terhadap Risiko ATR

ATR1 Saya tetap berhati-hati, bahkan ketika membelanjakan uang saku bulanan yang saya terima.
Sangat tidak setuju Sangat setuju
ATR2 Saya lebih nyaman menyimpan uang saya di rekening bank daripada di pasar saham.
Sangat tidak setuju Sangat setuju
ATR3 Ketika memikirkan kata “risiko”, istilah “rugi” langsung terlintas di benak saya.
Sangat tidak setuju Sangat setuju
ATR4 Dalam hal berinvestasi, keamanan lebih penting daripada imbal hasil.
Sangat tidak setuju Sangat setuju

Akses terhadap Layanan Keuangan AFS

AFS1 Lembaga keuangan terdekat (misalnya bank, kantor pos, perusahaan asuransi, perusahaan pembiayaan mikro, dll.) berjarak kurang dari 5 km dari tempat tinggal saya.
Sangat tidak setuju Sangat setuju
AFS2 Saya tinggal dalam radius kurang dari 1 km dari ATM yang mudah saya kunjungi.
Sangat tidak setuju Sangat setuju
AFS3 Saya menerima informasi mengenai transaksi saya dengan segera.
Sangat tidak setuju Sangat setuju
AFS4 Layanan keuangan yang disediakan oleh lembaga keuangan terjangkau bagi saya.
Sangat tidak setuju Sangat setuju
AFS5 Layanan keuangan yang saya terima dari lembaga keuangan sesuai dengan kebutuhan saya.
Sangat tidak setuju Sangat setuju
AFS6 Ketentuan pada lembaga keuangan mudah saya pahami untuk mengajukan produk keuangan.
Sangat tidak setuju Sangat setuju

Kendali Perilaku BC

BC1 Situasi keuangan saya sepenuhnya berada dalam kendali saya.
Sangat tidak setuju Sangat setuju
BC3 Saya dapat mengubah hal-hal penting dalam hidup saya dengan usaha saya sendiri.
Sangat tidak setuju Sangat setuju
BC4 Saya dapat menahan diri dari pembelian yang tidak perlu meskipun saya sedang tergoda.
Sangat tidak setuju Sangat setuju
BC5 Saya dapat dengan mudah mengelola pengeluaran saya apabila saya menghendakinya.
Sangat tidak setuju Sangat setuju

Literasi Keuangan FL

FL1 Inflasi yang tinggi berarti biaya hidup meningkat dengan cepat.
Sangat tidak setuju Sangat setuju
FL2 Lembaga keuangan menggunakan konsep diskonto (potongan bunga di muka) untuk menghitung besaran cicilan tetap, misalnya cicilan paylater.
Sangat tidak setuju Sangat setuju
FL3 Investasi dengan imbal hasil tinggi cenderung memiliki risiko yang lebih tinggi dari rata-rata.
Sangat tidak setuju Sangat setuju
FL4 Deposito berjangka bank menawarkan imbal hasil bunga yang besarannya sudah ditentukan sejak awal, sehingga jumlah keuntungannya dapat diketahui secara pasti sebelum jatuh tempo.
Sangat tidak setuju Sangat setuju
FL5 Penting untuk berinvestasi pada berbagai jenis aset guna mengurangi risiko kerugian.
Sangat tidak setuju Sangat setuju

Sikap Keuangan FA

FA2 Saya berpikir bahwa menyusun perencanaan keuangan sangatlah penting.
Sangat tidak setuju Sangat setuju
FA3 Saya berpikir bahwa mematuhi anggaran keuangan pribadi sangatlah penting.
Sangat tidak setuju Sangat setuju
FA4 Saya berpikir bahwa merencanakan pengeluaran uang penting untuk mengelola hidup seseorang dengan baik.
Sangat tidak setuju Sangat setuju
FA5 Saya berpikir bahwa memikirkan kondisi keuangan saya di masa depan penting bagi keberhasilan finansial saya.
Sangat tidak setuju Sangat setuju
FA6 Saya berpikir bahwa tujuan keuangan yang jelas dapat membantu saya menentukan prioritas dalam pengeluaran.
Sangat tidak setuju Sangat setuju

Sangat tidak setuju Sangat setuju

Sangat tidak setuju Sangat setuju
RFC6 Ketika membeli suatu barang, hal pertama yang saya pikirkan adalah apakah saya mampu membelinya.
